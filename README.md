# Sales Data Analytics | Data Warehousing & Business Intelligence

A data management and analytics solution for transforming bike sales data into structured, analysis-ready datasets through relational database design, dimensional modeling, data warehousing, OLAP, and visualization.

## Overview

This project explores the design of a sales analytics data platform, from structuring relational data to organizing it for analytical queries and business reporting. It combines database design principles with dimensional modeling and business intelligence techniques to support data-driven insights into sales performance.

## Key Components

 * **Relational Database Design:** Designed and structured database tables to organize sales data and establish relationships between entities.

 * **Database Normalization:** Applied normalization principles to improve data organization, maintain consistency, and reduce redundancy.

 * **Dimensional Modeling:** Developed a Star Schema to organize data for analytical queries and reporting.

 * **Data Mart & Data Warehouse:** Explored analytical data structures to support consolidated reporting and business analysis.

 * **OLAP Analysis:** Used multidimensional analytical concepts to examine sales data across relevant dimensions.

 * **Data Visualization:** Presented analytical findings through visualizations and KPI-focused reporting.

## Project Context

This project was developed as part of coursework in Data Management and Applications and demonstrates practical concepts in database design, data warehousing, and business intelligence.
